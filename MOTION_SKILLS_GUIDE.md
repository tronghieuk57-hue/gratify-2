# Motion & Interactive Design Pro — Companion Skills
This fork contains a curated gallery of community motion-video prompts, **not** ready-made frontend skills. The original gallery and author attributions remain intact.
## Added agent skills
- `.agents/skills/motion-director/SKILL.md` — accessible, performant animation workflows.
- `.agents/skills/visual-interactive-direction/SKILL.md` — visual system and interactive website design.
## Recommended use
Copy these skill folders into the website repository's `.agents/skills/` directory, or use them with a compatible agent that discovers project skills. The source gallery remains a reference; no original prompts are overwritten.
## Suggested stack
CSS for micro-interactions; GSAP + ScrollTrigger for choreography; Three.js for deliberate 3D; framework-native lifecycle cleanup. Pick only what the project needs.
## Verification
Check reduced motion, focus, touch, responsive layout, hydration, cleanup, runtime errors, and measured performance before shipping.
