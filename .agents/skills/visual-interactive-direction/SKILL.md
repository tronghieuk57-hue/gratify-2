# Visual & Interactive Direction
1. Derive a design brief: brand, audience, conversion goal, tone, reference mood, and accessibility constraints.
2. Define typography scale, spacing, contrast, color tokens, imagery style, grid, and responsive behavior before coding.
3. Create a purposeful hierarchy: one clear hero message, obvious primary action, and coherent navigation.
4. Use original or properly licensed visual assets. Never imply a referenced creator's footage is free for reuse.
5. For each section specify visual state, hover/focus state, mobile adaptation, and motion fallback.
6. Avoid heavy effects on every section; reserve visual spectacle for high-impact moments.
7. Validate image dimensions, alt text, responsive srcset, lazy loading below the fold, contrast, keyboard access and touch targets.
8. Deliver a component inventory, asset checklist, design tokens, responsive specs, and acceptance tests.
